Irrigação da Horta

Como ligar os fios, gravar o código no Arduino e testar cada parte antes de colocar água nas bombas.

Material Ligação Instalar e gravar Testar Problemas comuns Código

Material

  • 1 Arduino UNO + cabo USB
  • 1 módulo relé de 2 canais, bobina 5V
  • 1 sensor de chuva (placa + módulo LM393)
  • 1 botão (push button)
  • 1 bomba de alta pressão 12V
  • 1 bomba submersa 5V
  • 1 fonte 12V (corrente acima da bomba)
  • 1 fonte 5V separada para a submersa
  • Fios jumper macho-fêmea e macho-macho
  • Protoboard (opcional, ajuda nos testes)
Sobre os relés de 5V e 12V. O "5V" de um relé é a tensão da bobina, que é o lado que o Arduino comanda. Os dois relés devem ter bobina de 5V. Quem define se ele liga 5V ou 12V é o que você coloca nos contatos (COM e NO). Um módulo de 2 canais resolve as duas bombas de uma vez. Um relé com bobina de 12V não funciona direto no Arduino.

Diagrama de ligação

Cada cor de fio corresponde a uma ligação da tabela logo abaixo. Faça as ligações com o Arduino desconectado do USB e das fontes.

Ponto cheio = fios ligados. Fios que se cruzam sem ponto não se tocam. As trilhas verticais de 5V e GND podem ser as linhas da protoboard.

Tabela de ligações

D3Arduino pino 3DO do módulo do sensor

D8Arduino pino 8IN2 do relé, bomba SUBMERSA

Cuidados na ligação. Use sempre o terminal NO (normalmente aberto), assim a bomba fica desligada se o Arduino estiver sem energia. O NC fica sem ligar. As bombas nunca ligam no 5V do Arduino, cada uma tem a sua fonte. Como o relé separa os circuitos, as fontes das bombas não precisam ser ligadas no GND do Arduino. Isso corrige o que eu disse antes. Botão de 4 pernas: use duas pernas em diagonal, que é o jeito certo de garantir que ele abre e fecha. A placa do sensor vai na água, mas o módulo LM393 precisa ficar seco, fora do reservatório.

Instalar e gravar no Arduino

Não precisa de nenhuma biblioteca. O código usa só funções que já vêm no Arduino. Pode pular a parte do "Gerenciador de Bibliotecas".

  1. Instale a Arduino IDE

    Baixe em arduino.cc/en/software a versão 2.x para o seu sistema (Windows, macOS ou Linux) e instale normalmente. No Mac, arraste para a pasta Aplicativos.

  2. Abra o código

    Na IDE, vá em Arquivo → Abrir e escolha IrrigacaoHorta/IrrigacaoHorta.ino. O arquivo precisa ficar dentro de uma pasta com o mesmo nome (IrrigacaoHorta), senão a IDE pede para criar uma.

    Se você tem só o código, crie um sketch novo (Arquivo → Novo), apague tudo, cole o código da seção Código e salve com o nome IrrigacaoHorta.

  3. Conecte o Arduino e escolha a placa

    Ligue o Arduino no USB. Em Ferramentas → Placa → Arduino AVR Boards, escolha Arduino Uno.

  4. Escolha a porta

    Em Ferramentas → Porta, escolha a que aparece quando o Arduino está ligado:

    • Windows: COM3, COM4…
    • Mac: /dev/cu.usbmodem… ou /dev/cu.usbserial…

    Se nenhuma porta aparecer, veja Problemas comuns. Placas genéricas com chip CH340 às vezes precisam de driver.

  5. Verifique e grave

    Clique em ✓ Verificar. Deve terminar sem erros. Depois clique em → Carregar. Os LEDs TX/RX da placa piscam e no fim aparece "Carregamento concluído".

  6. Abra o Monitor Serial

    Clique na lupa no canto superior direito (ou Ferramentas → Monitor Serial) e selecione 9600 baud. Deve aparecer:

    Sistema pronto. Aperte o botao para iniciar o ciclo.

Testar por partes

Teste nesta ordem. Nos testes 1 a 4 as fontes das bombas ficam desligadas: dá para ver tudo pelos LEDs e pelo clique dos relés, sem risco de queimar bomba a seco.

Dica para os testes. No começo do código, troque os tempos máximos de 10 minutos para 1 minuto (1UL * 60UL * 1000UL). Assim você testa a proteção sem esperar muito. Depois volte ao valor normal.

  1. Botão

    Só o Arduino no USB e o botão ligado. Aperte o botão: o LED da placa (L) acende e o Monitor Serial mostra Ciclo iniciado. Aperte de novo: aparece PARADA DE EMERGENCIA e o LED apaga.

  2. Relés

    Ligue o módulo relé (sem as bombas). Ao ligar o Arduino, os dois relés precisam ficar desligados. Aperte o botão: o K1 (bomba de alta) dá um clique e o LED dele acende.

    Se os relés ligarem sozinhos assim que o Arduino liga, o seu módulo funciona ao contrário. Veja a seção de problemas.

  3. Sensor de chuva

    Ligue o sensor. Encoste um pano úmido ou pingue água na placa: o LED de sinal do módulo LM393 acende. Seque com papel toalha e ele apaga. Se não reagir, gire o parafuso azul (ajuste) aos poucos até o LED acender só quando está molhado.

  4. Ciclo completo, sem água

    Aperte o botão e molhe a placa do sensor. A sequência no Monitor Serial deve ser:

    Ciclo iniciado: bomba de ALTA ligada (irrigando).
Agua detectada no reservatorio do meio. Aguardando para desligar a ALTA...
Bomba de ALTA desligada. Aguardando 5 s para ligar a SUBMERSA...
Bomba SUBMERSA ligada: devolvendo agua para o reservatorio de alta.
Sensor seco: bomba SUBMERSA desligada. CICLO COMPLETO. Aperte o botao para novo ciclo.

    A última linha só aparece depois que você seca a placa. Entre as mensagens, confira o K1 desligar e, uns 5 segundos depois, o K2 ligar.

  5. Com bombas e água

    Agora ligue as fontes e coloque as bombas na água. Rode um ciclo inteiro olhando de perto, com a mão perto do botão para parar se precisar. Confira se a submersa desliga a tempo, sem secar o reservatório do meio.

    A placa do sensor de chuva demora para secar. Se a submersa continuar ligando depois que a água baixou, troque o sensor por uma boia de nível, que liga nos mesmos pinos (D3 e GND) sem mudar o código. Para a boia, use SENSOR_MOLHADO = LOW e ative o resistor interno trocando INPUT por INPUT_PULLUP na linha do sensor.

Problemas comuns

O que aconteceComo resolver
Nenhuma porta aparece na IDETroque o cabo USB (alguns só carregam e não passam dados). Placa genérica com CH340: instale o driver CH340 e reinicie a IDE.
Erro avrdude: stk500_recv() ao carregarPorta ou placa errada em Ferramentas. Confira se escolheu Arduino Uno e a porta certa.
Os relés ligam sozinhos quando o Arduino ligaSeu módulo liga com HIGH. No código, troque para RELE_LIGADO = HIGH e RELE_DESLIGADO = LOW.
O ciclo pula direto para "Agua detectada" com o sensor secoO sensor funciona ao contrário. Troque SENSOR_MOLHADO para HIGH, ou ajuste o parafuso do módulo.
O botão não faz nadaBotão de 4 pernas ligado com as duas pernas do mesmo lado. Use pernas em diagonal.
O Arduino reinicia quando a bomba ligaA bomba está puxando energia do Arduino. Cada bomba precisa da sua própria fonte, ligada só no relé.
Aparece "ERRO: tempo maximo"A bomba ficou ligada mais que o limite. Verifique se o sensor está na altura certa e bem ligado, ou aumente o tempo máximo se os reservatórios forem grandes.
Monitor Serial mostra símbolos estranhosVelocidade errada. Selecione 9600 baud.
Onde mudar os tempos

No começo do código, na parte de configurações:

  • TEMPO_ANTES_DESLIGAR_ALTA: espera depois que o sensor detecta água (2 s)
  • TEMPO_ANTES_LIGAR_SUBMERSA: espera entre desligar a alta e ligar a submersa (5 s)
  • TEMPO_CONFIRMA_SENSOR: quanto tempo o sensor precisa ficar molhado/seco para valer (1 s)
  • TEMPO_MAX_BOMBA_ALTA e TEMPO_MAX_BOMBA_SUBMERSA: limite de segurança (10 min)

Os valores estão em milissegundos: 1000 = 1 segundo.

Código

Arquivo IrrigacaoHorta.ino, completo e comentado.

/*
 * ==========================================================================
 *  SISTEMA DE IRRIGAÇÃO DA HORTA COM REAPROVEITAMENTO DE ÁGUA
 *  Placa: Arduino UNO
 * ==========================================================================
 *
 *  COMO O SISTEMA FUNCIONA
 *  -----------------------
 *  Existem três níveis:
 *    1) Reservatório de ALTA  -> tem a água e a BOMBA DE ALTA PRESSÃO (12V),
 *                                que alimenta os sprinklers da horta.
 *    2) Horta                 -> recebe a água dos sprinklers.
 *    3) Reservatório do MEIO  -> recebe a sobra da horta. Nele ficam o
 *                                SENSOR DE CHUVA (nível) e a BOMBA SUBMERSA (5V),
 *                                que devolve a água para o reservatório de alta.
 *
 *  SEQUÊNCIA DO CICLO (só começa ao apertar o botão):
 *    1. Botão pressionado  -> liga a bomba de alta (sprinklers).
 *    2. Sensor detecta água no reservatório do meio
 *                          -> espera TEMPO_ANTES_DESLIGAR_ALTA.
 *    3. Desliga a bomba de alta.
 *    4. Espera TEMPO_ANTES_LIGAR_SUBMERSA (5 segundos).
 *    5. Liga a bomba submersa (devolve a água para o reservatório de alta).
 *    6. Quando o sensor NÃO detecta mais água -> desliga a submersa.
 *    7. Ciclo completo. O sistema fica parado esperando o botão de novo.
 *
 *  SEGURANÇA EXTRA:
 *    - Apertar o botão DURANTE o ciclo desliga tudo (parada de emergência).
 *    - Cada bomba tem um tempo máximo de funcionamento. Se passar disso,
 *      tudo desliga (evita bomba queimar a seco ou transbordar se o
 *      sensor falhar).
 *
 *  LIGAÇÕES (pode mudar os pinos abaixo, se quiser)
 *  ------------------------------------------------
 *    Botão            -> pino 2 e GND  (usa o resistor interno, sem resistor externo)
 *    Sensor de chuva  -> saída DO no pino 3, VCC no 5V, GND no GND
 *    Relé bomba ALTA  -> IN no pino 7
 *    Relé SUBMERSA    -> IN no pino 8
 *    LED de status    -> LED da própria placa (pino 13)
 * ==========================================================================
 */

// ----------------------------- PINOS -------------------------------------
const int PINO_BOTAO          = 2;   // Botão de início (outro lado no GND)
const int PINO_SENSOR_CHUVA   = 3;   // Saída digital (DO) do sensor de chuva
const int PINO_RELE_ALTA      = 7;   // Relé da bomba de alta pressão (12V)
const int PINO_RELE_SUBMERSA  = 8;   // Relé da bomba submersa (5V)
const int PINO_LED            = 13;  // LED da placa: aceso = ciclo rodando

// --------------------------- CONFIGURAÇÕES -------------------------------
// A maioria dos módulos de relé para Arduino liga com sinal LOW (nível baixo).
// Se o seu relé ligar com HIGH, troque para:  RELE_LIGADO = HIGH, RELE_DESLIGADO = LOW
const int RELE_LIGADO    = LOW;
const int RELE_DESLIGADO = HIGH;

// O sensor de chuva comum (placa + módulo com LM393) manda LOW quando está
// MOLHADO. Se o seu funcionar ao contrário, troque para HIGH.
const int SENSOR_MOLHADO = LOW;

// Tempos (em milissegundos: 1000 ms = 1 segundo)
const unsigned long TEMPO_ANTES_DESLIGAR_ALTA  = 2000UL;    // espera após detectar água, antes de desligar a alta
const unsigned long TEMPO_ANTES_LIGAR_SUBMERSA = 5000UL;    // espera entre desligar a alta e ligar a submersa (5 s)
const unsigned long TEMPO_CONFIRMA_SENSOR      = 1000UL;    // sensor precisa ficar estável esse tempo (evita respingos)

// Tempos máximos de segurança (ajuste conforme o tamanho dos reservatórios)
const unsigned long TEMPO_MAX_BOMBA_ALTA     = 10UL * 60UL * 1000UL;  // 10 minutos
const unsigned long TEMPO_MAX_BOMBA_SUBMERSA = 10UL * 60UL * 1000UL;  // 10 minutos

const unsigned long TEMPO_DEBOUNCE_BOTAO = 50UL;  // filtro do ruído mecânico do botão

// ------------------------- ESTADOS DO CICLO ------------------------------
// O programa funciona como uma "máquina de estados": em cada momento ele
// está em UMA etapa do ciclo e só passa para a próxima quando a condição
// daquela etapa é cumprida.
enum Estado {
  PARADO,                  // esperando o botão
  IRRIGANDO,               // bomba de alta ligada, esperando o sensor detectar água
  ESPERANDO_DESLIGAR_ALTA, // água detectada, aguardando para desligar a alta
  ESPERANDO_SUBMERSA,      // alta desligada, aguardando 5 s para ligar a submersa
  RETORNANDO_AGUA          // submersa ligada, esperando o sensor secar
};

Estado estadoAtual = PARADO;
unsigned long inicioEstado = 0;   // momento (millis) em que entrou no estado atual

// Variáveis do botão (debounce)
int leituraBotaoAnterior = HIGH;
int estadoBotaoEstavel   = HIGH;
unsigned long ultimaMudancaBotao = 0;

// Variáveis do sensor (filtro de estabilidade)
bool sensorMolhadoEstavel = false;
bool ultimaLeituraSensor  = false;
unsigned long ultimaMudancaSensor = 0;

// ======================== FUNÇÕES AUXILIARES =============================

// Liga ou desliga a bomba de alta pressão
void bombaAlta(bool ligar) {
  digitalWrite(PINO_RELE_ALTA, ligar ? RELE_LIGADO : RELE_DESLIGADO);
}

// Liga ou desliga a bomba submersa
void bombaSubmersa(bool ligar) {
  digitalWrite(PINO_RELE_SUBMERSA, ligar ? RELE_LIGADO : RELE_DESLIGADO);
}

// Troca de estado, guarda o horário e mostra no Monitor Serial
void mudarEstado(Estado novoEstado, const char* mensagem) {
  estadoAtual  = novoEstado;
  inicioEstado = millis();
  Serial.println(mensagem);
}

// Tempo (ms) desde que entrou no estado atual
unsigned long tempoNoEstado() {
  return millis() - inicioEstado;
}

// Desliga tudo e volta ao estado PARADO
void pararTudo(const char* motivo) {
  bombaAlta(false);
  bombaSubmersa(false);
  digitalWrite(PINO_LED, LOW);
  mudarEstado(PARADO, motivo);
}

// Retorna true UMA vez quando o botão é apertado (já com debounce)
bool botaoFoiPressionado() {
  int leitura = digitalRead(PINO_BOTAO);
  bool pressionou = false;

  if (leitura != leituraBotaoAnterior) {
    ultimaMudancaBotao = millis();       // houve mudança: reinicia a contagem
  }

  if (millis() - ultimaMudancaBotao > TEMPO_DEBOUNCE_BOTAO) {
    if (leitura != estadoBotaoEstavel) {
      estadoBotaoEstavel = leitura;
      if (estadoBotaoEstavel == LOW) {   // LOW = apertado (usa INPUT_PULLUP)
        pressionou = true;
      }
    }
  }

  leituraBotaoAnterior = leitura;
  return pressionou;
}

// Atualiza a leitura do sensor: só aceita a mudança se ela ficar
// estável por TEMPO_CONFIRMA_SENSOR (evita respingos e ruído)
void atualizarSensor() {
  bool leitura = (digitalRead(PINO_SENSOR_CHUVA) == SENSOR_MOLHADO);

  if (leitura != ultimaLeituraSensor) {
    ultimaMudancaSensor = millis();
    ultimaLeituraSensor = leitura;
  }

  if (millis() - ultimaMudancaSensor >= TEMPO_CONFIRMA_SENSOR) {
    sensorMolhadoEstavel = leitura;
  }
}

// ============================== SETUP ====================================
void setup() {
  Serial.begin(9600);

  // Primeiro coloca os relés em "desligado" e só depois define como saída,
  // assim as bombas não dão um pulso ao ligar o Arduino.
  digitalWrite(PINO_RELE_ALTA, RELE_DESLIGADO);
  digitalWrite(PINO_RELE_SUBMERSA, RELE_DESLIGADO);
  pinMode(PINO_RELE_ALTA, OUTPUT);
  pinMode(PINO_RELE_SUBMERSA, OUTPUT);

  pinMode(PINO_BOTAO, INPUT_PULLUP);   // resistor interno: solto = HIGH, apertado = LOW
  pinMode(PINO_SENSOR_CHUVA, INPUT);
  pinMode(PINO_LED, OUTPUT);
  digitalWrite(PINO_LED, LOW);

  Serial.println("Sistema pronto. Aperte o botao para iniciar o ciclo.");
}

// =============================== LOOP ====================================
void loop() {
  atualizarSensor();
  bool apertou = botaoFoiPressionado();

  // Parada de emergência: botão apertado com o ciclo em andamento
  if (apertou && estadoAtual != PARADO) {
    pararTudo("Botao pressionado durante o ciclo: PARADA DE EMERGENCIA.");
    return;
  }

  switch (estadoAtual) {

    // ---------------------------------------------------------------
    case PARADO:
      // Só começa quando o botão for apertado
      if (apertou) {
        digitalWrite(PINO_LED, HIGH);
        bombaAlta(true);
        mudarEstado(IRRIGANDO, "Ciclo iniciado: bomba de ALTA ligada (irrigando).");
      }
      break;

    // ---------------------------------------------------------------
    case IRRIGANDO:
      // Espera a água chegar no reservatório do meio
      if (sensorMolhadoEstavel) {
        mudarEstado(ESPERANDO_DESLIGAR_ALTA, "Agua detectada no reservatorio do meio. Aguardando para desligar a ALTA...");
      }
      // Segurança: bomba de alta ligada tempo demais
      else if (tempoNoEstado() > TEMPO_MAX_BOMBA_ALTA) {
        pararTudo("ERRO: tempo maximo da bomba de ALTA atingido. Verifique o sensor/reservatorio.");
      }
      break;

    // ---------------------------------------------------------------
    case ESPERANDO_DESLIGAR_ALTA:
      if (tempoNoEstado() >= TEMPO_ANTES_DESLIGAR_ALTA) {
        bombaAlta(false);
        mudarEstado(ESPERANDO_SUBMERSA, "Bomba de ALTA desligada. Aguardando 5 s para ligar a SUBMERSA...");
      }
      break;

    // ---------------------------------------------------------------
    case ESPERANDO_SUBMERSA:
      if (tempoNoEstado() >= TEMPO_ANTES_LIGAR_SUBMERSA) {
        bombaSubmersa(true);
        mudarEstado(RETORNANDO_AGUA, "Bomba SUBMERSA ligada: devolvendo agua para o reservatorio de alta.");
      }
      break;

    // ---------------------------------------------------------------
    case RETORNANDO_AGUA:
      // Desliga quando o sensor não detectar mais água
      if (!sensorMolhadoEstavel) {
        bombaSubmersa(false);
        digitalWrite(PINO_LED, LOW);
        mudarEstado(PARADO, "Sensor seco: bomba SUBMERSA desligada. CICLO COMPLETO. Aperte o botao para novo ciclo.");
      }
      // Segurança: submersa ligada tempo demais (evita queimar a seco)
      else if (tempoNoEstado() > TEMPO_MAX_BOMBA_SUBMERSA) {
        pararTudo("ERRO: tempo maximo da bomba SUBMERSA atingido. Verifique o sensor.");
      }
      break;
  }
}
